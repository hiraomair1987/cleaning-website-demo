# Cleaning business website demo (EfficioVirtual)

A demo landing page for **Brightway Cleaning Co.**, a fictional Houston cleaning company. Send it to cleaning-business leads to show what their website could look like.

Everything business-specific is sample content: the name, the (713) 555-01xx phone number, the example.com email, the trust points and the review cards. Photos are AI-generated placeholders.

## View or deploy

Open `index.html` in a browser; there's no build step. To deploy, import this repo in Vercel (Framework preset: Other) or enable GitHub Pages on `main`.

## Turning it into a client site

Copy the folder, then replace the brand name, logo mark (`#logo-mark`), phone, email, service area, services, trust points, reviews (real ones, with permission), FAQ answers and photos. Remove the demo bar, the "Like this website?" section and the `noindex` meta tag, and connect the quote form to a real form backend.
